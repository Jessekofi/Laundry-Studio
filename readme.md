# Laundry Studio
Laundry Studio is a clean, modern, and user-friendly website designed for a professional laundry service. The website provides customers with information about the business, its services, inquiry options, and contact details.


Changes based on part 2 feedback
-Improved centering and alignment
-Adjusted logo size for better visibility and balance 
-Improved spacing between sections 
-Refined the blue colour scheme for a cleaner mordern look
-Improved readability of headings and text

## Part 2 Details

### CSS Styling

- **Stylesheet:** `css/style.css`
- **Fonts:** Montserrat (headings), Open Sans (body)
- **Colour Scheme:**
  - Sky Blue: #87CEEB
  - Azure: #007FFF
  - Navy Blue: #000080
  - Turquoise: #40E0D0
  - Ice Blue: #F0F8FF
  - Black: #000000

### Layout Techniques

- **Flexbox:** Header, Navigation, Hero section
- **CSS Grid:** Services grid (4 columns desktop, 2 tablet, 1 mobile)
- **CSS Grid:** Testimonials grid (3 columns desktop, 2 tablet, 1 mobile)

### Responsive Design

| Breakpoint | Screen Size | Changes |
|------------|-------------|---------|
| Desktop | 1024px+ | 4-column grid, horizontal nav |
| Tablet | 768px - 1024px | 2-column grid, stacked header |
| Mobile | 480px - 767px | 1-column grid, vertical nav |
| Small Phone | Below 480px | Smaller fonts, stacked layout |
